# Fábrica Chañar

MVP de una fábrica digital local para San Patricio del Chañar, desarrollada dentro de `universo-ocarina`.

## Acceso

Si GitHub Pages está activo para este repositorio, la ruta pública es:

`/fabrica/`

## Principios

- navegador primero
- sin instalación
- sin cuenta paga
- sin backend obligatorio
- datos guardados localmente en el navegador
- exportación PNG/JPG/PDF
- responsive para celular y PC
- plantillas modulares
- fuentes y datos verificables

## MVP actual

- generador de postales
- fichas locales
- guías breves
- mapas esquemáticos
- cinco plantillas por categoría
- carga de imagen local
- biblioteca local con localStorage
- exportación PNG/JPG/PDF
- impresión
- exportación de biblioteca JSON

## Próxima evolución

1. biblioteca real de lugares y fuentes verificadas

3. plantillas editoriales avanzadas
