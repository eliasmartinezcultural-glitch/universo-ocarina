# Productos Ocarina Lab

Esta carpeta contiene los **archivos maestros y piezas listas para entrega** del catálogo.

## Regla

Un producto solo pasa a `Disponible` cuando el archivo final existe y fue controlado.

## Organización

- `mapas/` — mapas e interpretaciones territoriales.
- `postales/` — postales digitales individuales o series.
- `posters/` — piezas gráficas para impresión.
- `laminas/` — láminas artísticas.
- `pixel-art/` — piezas del universo pixel art.
- `packs/` — colecciones agrupadas.

## Convención de nombres

`SKU_nombre_version.ext`

Ejemplo: `OC-LAB-POST-009_chanar-de-noche_v01.svg`

## Importante

Los archivos de esta carpeta son productos digitales. Las piezas generadas con IA deben pasar por selección, dirección y control de Ocarina antes de publicarse como disponibles.
