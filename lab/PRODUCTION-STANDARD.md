# OCARINA LAB · ESTÁNDAR PROFESIONAL DE PRODUCCIÓN

## Identidad visual obligatoria

La fábrica adopta una estética de **terrunio rural contemporáneo**: tierra, chacra, agua, álamos, cielo, madera, papel, herramientas de campo y paisaje patagónico reinterpretados de manera artística.

### Paleta

Solo colores pastel y tonos suaves. Base recomendada:

- crema `#F4EBDD`
- arena `#E7D6BE`
- trigo `#DCC8A6`
- salvia `#B8C8B0`
- oliva suave `#A9B59A`
- celeste río `#B7D1D0`
- cielo `#C9D9E4`
- rosa tierra `#D9B9B2`
- terracota pastel `#CFA38E`
- lavanda tierra `#C8BDD0`
- carbón suave `#45433E`
- blanco `#FFFDF8`

No usar negro puro, colores fluorescentes, saturaciones agresivas ni interfaces de aspecto tecnológico frío salvo que una pieza artística concreta lo justifique y sea convertida a pastel.

## Producción rápida

### Catálogo

**Buscar → abrir → descargar → enviar.**

### A medida

**Elegir plantilla → cambiar variables → previsualizar → fabricar → descargar → enviar.**

El objetivo operativo es que una personalización sencilla pueda resolverse en minutos.

## Sistema de entregas

Cada fabricación debe ofrecer dos niveles:

### 1. MASTER

Archivo de máxima calidad disponible, normalmente SVG/vectorial cuando la pieza lo permite.

Uso:
- archivo fuente de entrega;
- impresión;
- futuras adaptaciones;
- conservación de calidad.

### 2. COPIAS DE ENVÍO

Versiones optimizadas para comunicación digital.

| Canal | Tamaño | Formato | Calidad orientativa |
|---|---:|---|---:|
| WhatsApp | 1080×1080 | JPG | 84 % |
| Instagram cuadrado | 1080×1080 | JPG | 86 % |
| Instagram vertical | 1080×1350 | JPG | 86 % |
| Historia / vertical | 1080×1920 | JPG | 84 % |
| Facebook horizontal | 1200×630 | JPG | 86 % |
| General / presentación | 1600×900 | JPG | 88 % |

La exportación social es una copia. **Nunca reemplaza el master.**

## Nombres de archivo

Usar siempre:

`SKU_nombre_formato.ext`

Ejemplo:

`OC-LAB-RIO-007_rio-neuquen_whatsapp.jpg`

Esto permite localizar un archivo sin abrirlo.

## Control antes de descargar

El generador debe revisar visualmente:

- título legible;
- textos dentro del área segura;
- ausencia de desbordes;
- proporción correcta;
- contraste suficiente dentro de la estética pastel;
- ausencia de caracteres rotos;
- SKU correcto;
- variante correcta;
- formato correcto.

## Entrega ideal

Si un pedido requiere una pieza para redes, la descarga ideal debe producir el paquete mentalmente así:

**MASTER + WHATSAPP + INSTAGRAM + STORY + FACEBOOK**

No obligar al creador a repetir el trabajo cinco veces.

## Referencia interna de precios

Son referencias operativas, no precios oficiales y deben revisarse periódicamente:

- Postal: $8.000–$15.000
- Lámina: $15.000–$30.000
- Póster: $20.000–$40.000
- Pixel art: $15.000–$35.000
- Guía: $25.000–$60.000
- Mapa: $30.000–$80.000
- Pack: $40.000–$100.000
- Personalización: +50 % a +100 % según trabajo
- Urgencia: +25 % a +50 % según plazo

El precio final debe considerar complejidad, cantidad de piezas, uso, urgencia y necesidad de investigación.

## Regla comercial

El precio no se calcula por cantidad de clics del generador. Se cobra el valor de la pieza, el criterio creativo, la investigación cuando exista, la personalización y el resultado.

## Regla de mejora continua

Cada pedido nuevo debe dejar al sistema más preparado para el siguiente:

**pedido nuevo → nueva variable / plantilla / mejora → próximo pedido más rápido.**

## Objetivo final

La fábrica debe sentirse como un pequeño taller rural digital:

**abrir → elegir → tocar unas pocas cosas → ver → fabricar → descargar.**

Mucho trabajo detrás de escena. Muy poco trabajo visible para el creador.
