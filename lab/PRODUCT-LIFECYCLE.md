# Ocarina Lab · Ciclo de vida de producto 2.0

## Principio

Un producto es un activo terminado del equipo Ocarina: se encuentra, verifica, fabrica y entrega sin rehacer el trabajo.

## Estados

`IDEA → LAB → QA → AVAILABLE → ARCHIVED`

## Regla de jurisdicción

**Ocarina Lab es exclusivamente interno.** El cliente no opera la fábrica, no administra productos, no accede a procesos internos ni participa en fabricación. Solo recibe el resultado que Ocarina decide entregar.

## Gate de publicación

Antes de `AVAILABLE`:

- [ ] SKU único.
- [ ] Nombre claro.
- [ ] Familia definida.
- [ ] Fuente maestra existente.
- [ ] Integridad factual revisada.
- [ ] Si representa un lugar real: referencias verificadas y representación fiel.
- [ ] Si es interpretación artística: está declarada como tal.
- [ ] Fotografía propia/autorizada si corresponde.
- [ ] Marca Ocarina discreta.
- [ ] PDF probado.
- [ ] JPG probado.
- [ ] Nombre de archivo correcto.
- [ ] El comprador no recibe fuentes internas.
- [ ] Precio de referencia interno definido.

## Ley de representación territorial

Un producto que diga o sugiera que representa un lugar concreto de San Patricio del Chañar debe partir de referencias reales verificadas.

**No se inventan calles, edificios, plazas, accesos, chacras, puentes, cursos de agua ni ubicaciones y luego se presentan como reales.**

Puede haber estilización, pero la estilización no puede convertirse en falsificación territorial.

`REFERENCIA REAL → VERIFICACIÓN → COMPOSICIÓN → ESTILO OCARINA`

## Personalización

Según la plantilla, pueden estar habilitados:

`nombre · dedicatoria · fecha · lugar · frase local · foto autorizada · variante · orientación · tamaño · edición`

La personalización modifica la obra sin modificar falsamente los hechos del territorio.

## Línea local: “Recuerdito de San Patricio del Chañar”

Se habilita como familia editorial reutilizable para postales, láminas, pósters, packs y derivados.

Frase base opcional:

**“Un recuerdito de San Patricio del Chañar”**

Derivados posibles: `Recuerdito de mi Chañar`, `Un pedacito del Chañar`, `Mi Chañar` y otras variantes creadas por Ocarina.

No son afirmaciones históricas por sí mismas; son recursos editoriales y comerciales.

## Reutilización

Cada obra terminada debe evaluarse para:

`FOTO → POSTAL → LÁMINA → PÓSTER → PACK → REDES`

`LUGAR VERIFICADO → POSTAL → LÁMINA → PÓSTER → GUÍA VISUAL → PACK`

`INVESTIGACIÓN → GUÍA → MAPA → LÁMINA → PACK`

Cada hora de trabajo debe aumentar el inventario futuro.

## Seguridad editorial

GitHub Pages es un espacio público, no una bóveda privada. Los masters privados, originales sensibles y datos de compradores deben mantenerse fuera del repositorio público.
