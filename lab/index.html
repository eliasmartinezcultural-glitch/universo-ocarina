EL MODELO OCARINA LAB

Simple para quien compra. Sostenible para quien crea.

01 · CREAR

Ocarina produce primero.

Las piezas se diseñan sin esperar pedidos ni recopilar información de clientes.

02 · PUBLICAR

El catálogo hace el trabajo.

Cada producto tiene nombre, categoría, descripción y una presentación clara.

03 · VENDER

Elegís y coordinamos.

La compra se inicia por WhatsApp. El producto ya está creado; solo falta concretar pago y entrega.

REGLA DEL LABORATORIO

No hacemos encargos para esta línea.

Ocarina Lab está pensado como catálogo de productos terminados. Eso permite producir con calma, mantener una identidad visual consistente y vender una misma pieza más de una vez. Las personalizaciones, si alguna vez se ofrecen, serán una línea comercial distinta.
