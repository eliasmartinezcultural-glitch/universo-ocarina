# Biblioteca Visual Ocarina · 1.0

La Biblioteca Visual es el banco editorial de imágenes y referencias reales que alimenta la fábrica artística.

## Objetivo

Convertir fotografías propias o debidamente autorizadas de San Patricio del Chañar y su territorio en **activos reutilizables** para postales, láminas, pósteres, mapas artísticos, guías, packs y piezas para redes.

## Regla principal

Una fotografía no entra a producción solo porque existe. Debe tener procedencia y estado de uso claros.

Estados:

- `candidate` — material recibido, todavía no aprobado.
- `approved` — puede utilizarse según la licencia registrada.
- `restricted` — puede usarse solamente bajo condiciones indicadas.
- `archived` — no utilizar.

## Registro mínimo por imagen

- ID interno.
- Archivo.
- Fecha de incorporación.
- Zona o referencia territorial.
- Tema visual.
- Autoría.
- Estado de autorización.
- Usos permitidos.
- Observaciones.

## Categorías Ocarina

- río
- chacras
- álamos
- caminos rurales
- bardas
- paisaje urbano
- arquitectura
- patrimonio
- producción rural
- atardecer / cielo
- detalles del territorio
- personas, únicamente cuando corresponda y exista autorización para el uso previsto

## Uso editorial

La biblioteca no obliga a usar fotografía literal. Una imagen aprobada puede ser:

1. fotografía protagonista;
2. fondo editorial;
3. textura o recorte;
4. referencia para una interpretación artística;
5. elemento de una colección.

## Prohibiciones

- No incorporar fotografías de terceros sin permiso suficiente.
- No presentar una recreación como fotografía documental.
- No alterar una imagen de manera que convierta un dato visual relevante en una falsedad.
- No guardar datos personales innecesarios.
- No publicar material sensible.

## Flujo

**RECIBIR → IDENTIFICAR → VERIFICAR AUTORÍA → CLASIFICAR → APROBAR → CATALOGAR → REUTILIZAR**

La biblioteca debe reducir trabajo futuro: cada activo aprobado debe poder alimentar múltiples productos sin volver a investigar su procedencia.
