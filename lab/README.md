# Ocarina Lab

Laboratorio comercial de productos digitales de Ocarina Producciones.

## Principio

**Ocarina crea → publica → el público descubre → compra → recibe.**

Los productos del Lab se diseñan antes de la venta. La línea busca evitar trabajos personalizados, formularios y producción bajo pedido.

## Arquitectura actual

- `lab/index.html`: catálogo público.
- Productos organizados por categorías.
- Fichas comerciales mediante interfaz modal.
- Contacto de compra mediante WhatsApp.
- Sin dependencia de frameworks ni servicios pagos.

## Próxima etapa

1. Definir precio y SKU de cada producto.
2. Producir archivos maestros reales.
3. Crear portadas/mockups definitivos.
4. Organizar una biblioteca privada de entregables.
5. Incorporar un método de pago definido.
6. Medir consultas, conversiones y productos más vendidos.

## Regla comercial

No publicar un producto como disponible hasta que exista realmente el archivo final que se entregará al comprador.
