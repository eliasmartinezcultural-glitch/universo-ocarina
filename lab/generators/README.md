# Generadores Ocarina Lab

Los generadores son herramientas internas para fabricar productos repetibles del territorio del Chañar.

## Arquitectura

Cada generador debe tener:

- selector de familia;
- nombre del producto;
- SKU;
- serie/edición;
- formato;
- título y subtítulo;
- contenido editable;
- botón de generar;
- preview;
- botón de descarga;
- registro del producto en el inventario.

## Primeras fábricas

- `postales.html` — generador de postales.
- `guias.html` — generador de guías.
- `laminas.html` — generador de láminas.
- `mapas.html` — generador de mapas conceptuales.
- `packs.html` — generador de colecciones.

La generación debe producir archivos autónomos, sin dependencias externas de pago.
