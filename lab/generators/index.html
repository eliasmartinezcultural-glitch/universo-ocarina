Producto afuera.

La fábrica existe para transformar pedidos en piezas terminadas sin empezar de cero. Las plantillas, la investigación y la automatización trabajan antes; cuando llega el pedido, vos decidís, fabricás, descargás y enviás.

FLUJO UNIVERSAL
PEDIDO → PLANTILLA → CAMBIOS → PREVIEW → FABRICAR → DESCARGAR → ENVIAR → FIN
⚡ Modo catálogoEl producto ya existe. No se fabrica nuevamente.BUSCAR → DESCARGAR → ENVIAR
✦ Modo a medidaEl producto nace desde una plantilla reutilizable y se personalizan solo las variables necesarias.CAMBIAR → PREVIEW → FABRICAR → DESCARGAR

LEY OPERATIVA: la tecnología debe acelerar la producción, no convertirse en trabajo. Si una tarea se repite, se convierte en plantilla. Si un producto se vende más de una vez, se convierte en catálogo. Si un pedido es nuevo, debe dejar una herramienta mejor preparada para el próximo.
