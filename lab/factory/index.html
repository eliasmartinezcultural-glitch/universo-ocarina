La fábrica encendida.

Un único lugar para fabricar, revisar y localizar productos del Chañar. La regla es simple: cada pieza debe existir antes de venderse y cada archivo terminado debe tener SKU.

INVENTARIO MAESTRO

Encontrar y entregar.

Buscá por SKU, nombre o familia. El enlace del archivo aparece solamente cuando el producto ya tiene archivo asociado.

Este panel es operativo, no un sistema de autenticación. El repositorio actual es público: ocultar un enlace no convierte un archivo en privado. La protección real de masters deberá resolverse con almacenamiento privado cuando corresponda.
